# PlayGround

A playground for Google Workspace/Drive APIs and PDF structural parsing. Two independent
tools live here.

## 1. Directory/Drive web app (`app.py`)

A FastAPI app with "Sign in with Google" (OAuth2). Once logged in, a user can:

- List all names/emails in the `aot-technologies.com` Workspace directory (via the People
  API, falling back to the Admin SDK Directory API for admin accounts).
- List the subfolders of a fixed Google Drive folder.
- Cross-check directory users against Drive folder names by fuzzy name match (word-by-word
  similarity, not raw character-sequence matching — naive whole-string matching produced
  false positives on short names), surfacing:
  - users with no matching folder, and
  - folders with no matching active user.

### Setup

Needs a **Web application**-type OAuth 2.0 client in Google Cloud Console, with:
- APIs enabled: People API, Admin SDK API, Google Drive API
- Authorized redirect URI: `http://localhost:8000/auth/callback`
- Downloaded as `credentials.json` in the project root

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

export SESSION_SECRET=$(python -c "import secrets; print(secrets.token_hex(32))")
python -m uvicorn app:app --reload
```

Then open `http://localhost:8000` (use `localhost`, not `127.0.0.1` — the two are treated
as different origins by the session cookie, and the login flow will fail if you mix them).

## 2. BCBC MO Package PDF indexer (`src/bcbc_mo_index.py`)

Parses `MO Package BCBC MRK signed.pdf` (a 1685-page merged BC Building Code + Ministerial
Order package whose own PDF bookmarks are too coarse to use directly) into a full
hierarchical index:

```
Volume → Division → Part → Section → Subsection → Article → Sentence → Clause → Subclause
                       └── Notes to Part → Note
```

plus a Table/Figure index. Heading detection relies on font metadata (`Arial-Black` for
real headings, `Arial-BoldMT` for real Table/Figure captions) to reject citation references
that merely wrap to the start of a line.

Output: `output/bcbc_mo_index.json` (full fidelity, including Sentence/Clause/Subclause) and
`output/bcbc_mo_index.md` (human-readable index with page numbers and lengths).

### Usage

```bash
# defaults to data/MO Package BCBC MRK signed.pdf
python src/bcbc_mo_index.py

# or index a different PDF
python src/bcbc_mo_index.py /path/to/other.pdf
```

## 3. Directory-access CLI check (`src/check_directory_access.py`)

A standalone script that checks, outside the web app, whether a given Google account can
list the Workspace directory via the People API vs. the Admin SDK, and prints which path
works and why.

Needs a **Desktop app**-type OAuth 2.0 client (separate `credentials.json` from the web
app's — desktop and web clients aren't interchangeable).

```bash
python src/check_directory_access.py
```

## Folder structure

- `app.py` — the FastAPI app; stays in the project root as its own entry point.
- `src/` — every other Python script (`bcbc_mo_index.py`, `check_directory_access.py`).
  Both anchor their file paths (credentials, token, PDF, output) to the project root, not
  the current working directory, so they run correctly regardless of where they're invoked
  from.
- `data/` — input source files, e.g. `MO Package BCBC MRK signed.pdf`.
- `output/` — everything a program run produces (`bcbc_mo_index.json`, `bcbc_mo_index.md`,
  and any future result file). Regenerated by re-running the producing script; safe to
  delete and rebuild.
- `ai_docs/` — design notes and reports written during development, distinct from `output/`.
- Root also holds `credentials.json` / `token.json` (OAuth secrets — never commit these if
  this ever becomes a git repo) and `requirements.txt`.
